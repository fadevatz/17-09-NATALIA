- **Verde Menta Suave (`#E4F4F0`)**: Fundo de cards secundários e áreas explicativas.

## 🚀 Como Executar Localmente

### Pré-requisitos
- Node.js 18+ instalado

### Instalação & Execução
```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev
```
Acesse em: `http://localhost:3000`

---

## 🐳 Execução via Docker (Pronto para Deploy)

### 1. Construir a Imagem Docker
```bash
docker build -t natalia-landingpage .
```

### 2. Rodar o Container na Porta 80
```bash
docker run -d -p 80:80 --name natalia-site natalia-landingpage
```
Acesse em: `http://localhost`
